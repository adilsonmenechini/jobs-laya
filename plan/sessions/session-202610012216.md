## O que mudou

- `app/sources/gupy.py` — `GupySource` sobre a API aberta
  `GET /api/job-search/jobs` (`jobName`, `limit`, `offset`), sem login e sem
  browser. Pagina por `offset` com `gupy_page_size` e para em página curta ou
  vazia. `location` é mapeado com cuidado: `remoto`/`remote` →
  `workplaceType=remote` (nunca `city=remoto`), nome completo de estado →
  `state=` (27 UFs), resto → `city=`, `Brazil`/`brasil` → sem filtro.
  `normalize_item` formata `location` como `Cidade - UF`, limpa HTML/entities e
  trunca `posted_at` em 100 chars (limite da coluna). `details()` só consulta a
  página SSR (`__NEXT_DATA__` → `props.pageProps.job.description`) quando a
  busca veio sem descrição.
- `app/sources/glassdoor.py` — `GlassdoorSource` com engine injetável
  (Protocol `goto`/`wait`/`evaluate`): os testes usam `FakeEngine` + fixture,
  o runtime usa `PatchrightGlassdoorEngine` (Chromium local, headful). Desafio
  do Cloudflare detectado pelo `title` **antes** do `wait` → fail fast com
  `SourceUnavailableError` em vez de esperar 30 s. Parser por
  `li[data-test="jobListing"]` com seletores `data-test`/`[class*=…]`
  independentes de hash de classe; `source_id` vem do `?jl=` da URL.
  `details()` é no-op documentado (todas as rotas de detalhe caem no desafio —
  spec Non-Goals) e nunca levanta exceção.
- `app/sources/__init__.py` — `source_names()`/`build_sources()` com
  `gupy`/`glassdoor`; o engine do Glassdoor fica `None` até o primeiro
  `search()`, então `/health` e o registry continuam baratos e nunca abrem
  Chromium.
- `app/config.py` — 8 settings novos (`gupy_*`, `glassdoor_*`; defaults
  `gupy_page_size=10`, `glassdoor_delay_seconds=2.0`,
  `glassdoor_timeout_ms=30000`, `glassdoor_headless=false`).
- `app/main.py` (regex do query `source`), `app/schemas.py` (Literal),
  `app/static/index.html` (opções nos dois selects), `.env.example`,
  `README.md` (seção 5, árvore do projeto, limitações).
- Testes (escritos antes do código) + fixtures reais reduzidas:
  `tests/test_gupy_source.py` (22), `tests/test_glassdoor_source.py` (13),

  "Um momento…") → `glassdoor_headless: bool = False` como default.
- Um Chromium por `search()`, fechado no `finally` (nenhum processo vaza);
  delay aplicado pela fonte, não pelo engine.
- Fixtures reduzidas a partir dos payloads brutos capturados (6 cards do
  Glassdoor, 4 itens da Gupy, JSON-LD/`__NEXT_DATA__` aparados).

## Bugs encontrados no REVIEW e corrigidos

1. `make_source` dos testes re-passava `gupy_page_size`/`glassdoor_delay_seconds`
   duplicado → `TypeError`; virou dict de defaults + overrides.
2. `await closer.close() if cond else closer.stop()` parseia como
   `(await closer.close()) if cond else closer.stop()`, deixando `pw.stop()`
   (o `__aexit__` do context manager do Patchright) como coroutine nunca
   aguardada → RuntimeWarning. Shutdown reescrito com `if` explícitos e
   revalidado com `python -W error::RuntimeWarning`.

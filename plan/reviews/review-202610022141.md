## Problemas encontrados e próximo passo

### **Hipótese refutada: confidence gating**

O SPEC propunha usar `role_confidence` do Laya para ponderar a fusão. **Resultado: regressão de 12/18 → 7/18.**

**Causa raiz:**
1. O checkpoint Laya real tem **confianças mal calibradas** (warning do Laya: "invalid temperatures")
2. Quando `role_confidence < 0.5`, o gating ignora o Laya completamente → cai para heurística (16/18)
3. Mas a heurística sozinha já é forte — o Laya precisa **complementar**, não ser gateado

**Decisão:** Reverter para política 50/50 (baseline 12/18). O confidence gating é uma **hipótese falhada** com o checkpoint atual.

### **Veto de exclusão do Laya: desabilitado**

A pergunta `exclusions` foi adicionada ao Laya, mas o checkpoint atual **não foi treinado** com ela. Resultado: falsos positivos (`ai-engineer-llm-remote-en` → low por exclusão fantasma).

**Decisão:** Desabilitar o veto de exclusão do Laya até fine-tuning.
